PORTFOLIOサイト

担当範囲
デザイン・コピー/ライティング・構成・素材選定/編集
制作期間
2ヶ月
使用ツール
illustrator , Photoshop , Figma , VS Code , GitHub

たんぽぽをモチーフに、コンセプト設計からデザイン、コーディングまで一貫して制作。
花や綿毛のあしらい、柔らかな色合いで世界観を表現しました。
また、サービス内容や制作実績を整理し、知りたい情報へスムーズにたどり着ける構成に。デザインの雰囲気だけでなく、自分の想いや人柄も伝わるサイトを目指しました。
